# Component and license evaluation

Evaluated 2026-11-16 using the linked upstream repositories. Availability or README claims do not verify hardware performance, security, or quality. No third-party assistant application source was copied into the repository. The optional speech runtime/model is downloaded only after a user confirms its native prompt and is not included in the installer.

Other adopted dependencies: rusqlite/SQLite for local storage and safe backup APIs; sysinfo for supported OS resource readings; reqwest/rustls for bounded native HTTPS; serde/serde_json, UUID, chrono, Windows bindings, zeroize, SHA-256 and base64 for their narrowly scoped functions; Zod for frontend trust-boundary validation. Vanilla CSS/SVG, icons and core geometry are original code in this repository. The supplied reference remains a design reference, not a bundled product background.

Wake-word detection uses the installed Windows recognizer and accepts `JARVIS` alone. Optional Whisper handles a bounded, on-demand 10-second command recording offline; SAPI remains the fallback. Available recognizers and voices depend on Windows language packs. No actor clone, guaranteed British male voice, or guaranteed Egyptian Arabic/mixed-language quality is included. The current synthetic Whisper sample measured about 3.7 seconds with the model unloaded afterward; real microphone quality and latency still need user testing.

### Optional Piper adapter continuation

JARVIS now supports user-selected local Python (`piper-tts`), ONNX model and adjacent matching `.onnx.json` config through existing Settings. The engine and model are not downloaded, bundled or redistributed. The adapter uses Piper's documented isolated module/CLI workflow with model/output/input-file arguments; Windows speech remains the fallback. Actual local import/synthesis/playback is not verified because no Piper environment/model was selected. Upstream notes that CLI model reload adds latency: https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/CLI.md

The requested high JARVIS model card states it was fine-tuned from U.S. lessac high; its Dataset section supplies no dataset license. Retain and review the model card with a local copy: https://huggingface.co/jgkawell/jarvis/blob/main/en/en_GB/jarvis/high/MODEL_CARD . Piper distinguishes its engine license from model/data rights and notes the relevance of the full training lineage: https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/LICENSING.md . The adapter does not claim movie-voice identity, legal clearance or verified human quality.
